# 0.4.0

- 将抖音评论与钉钉导航归并为 skills 下的独立 Skill，各自承载配置、运行器、启动器、测试与文档。
- 分离共享 Win32、截图和路径解析，移除根目录平台业务入口。
- 新增 douyin-reply-rpa：采集评论、由当前 AI 筛选明确需求并生成 Sparnow 回复、预演与授权定向回复；按评论和用户双维去重，未知结果禁止重试。
- 两个抖音 Skill 共用浏览器、URL 与评论区基础代码、桌面互斥和真实提交时间账；按用户最新要求，定向回复的发送和下一视频间隔为 10 秒，顶层评论保留自己的配置。
- 定向回复默认持续处理，取消默认 3 次及累计发送数量上限；用户明确要求时由系统持久目标驱动 AI 接续。保留原评论、作者、收件人、草稿与焦点核验，目标核验失败时保存页面证据。
- 整理数据与构建目录，保留历史状态；独立包支持三个 Skill。Skill 默认仅保存在项目 skills，未经明确要求不注册到全局库。

# 0.3.2 — 2026-10-12

- 发送最小间隔改为 10 秒；任务状态返回实际加载值与等待截止时间。
- 新增每 2 秒刷新的独立窗口和托盘监控，持续任务自动启用，支持手动再次打开。
- 新增运行器心跳，区分进展、存活和响应；检测验证码、异常退出和心跳超时。
- 增加监控单实例、刷新、卡住/退出识别、验证码状态及重启后跟随回归。

# 0.3.1 — 2026-10-12

- 按用户要求取消提交后刷新和可见性检查，发送动作完成即记录 Submitted。
- 单条异常保留去重记录并跳过，仅验证码触发人工等待；浏览器不可用时等待恢复。
- 增加提交数、跳过数、可恢复错误及相应回归测试。

# 0.3.0 — 2026-10-12

- 项目根目录直接作为 windows-rpa Skill，提供 AI 调用说明、任务协议和独立打包。
- 新增 JSON 任务、后台启动、进程身份状态查询、暂停确认、恢复及停止接口。
- 接续原去重记录，区分控制请求与实际状态；新增后台控制和目录迁移回归。

# 0.2.0 — 2026-10-12

- 默认入口切换为抖音评论原生 RPA；增加选题搜索、真实视频链接收集、标题过滤及持续轮询。
- 新增原生 Unicode 输入、地址及文档双重目标校验、自动切回 Chrome 和实时标题栏激活。
- 提交前排他落盘，跨运行去重；验证码等待、结果不明停止；区分即时提交和重新打开后的评论可见性。
- 增加预演、检查、持续发布、暂停、恢复、停止启动器及状态/输入保护测试。
- 保留钉钉兼容场景；新版持续发布尚未进行长时间耐久测试。
