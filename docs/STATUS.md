## 实际边界

- 自动切回采用标准窗口激活和实时标题栏命中点击；仍需真实可用的 Windows 桌面。锁屏、完全遮挡、系统拒绝激活、页面结构改变均可能使流程停止。
- 窗口与评论控件来自当前页面 UIA；部分 CSS 类名随网站改版变化，需重新检查后更新配置。
- 连续运行与有限处理共用流程；当前没有长时间无人值守耐久验证。
- 历史钉钉证据、旧入口和兼容代码保留。钉钉原有焦点恢复行为未被改成抖音策略。
